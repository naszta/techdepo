## Overview

The Meridian A620M Lite is a budget Micro-ATX AM5 board. It has two DDR5 slots (up to 64 GB,
rated to 6000 MT/s), one M.2 slot at PCIe 4.0 for NVMe drives, four SATA ports and a PCIe 4.0 x16
graphics slot. It is a sensible base for an affordable DDR5 system with a Quartz CPU such as the
Voltaris V5 7600.

Watch the BIOS. The board ships with BIOS 8, and second-generation Obsidian CPUs (V5 8600, V7 8700,
V9 8950) need BIOS 15. It has no BIOS flashback, so updating needs a working Quartz CPU installed
first. If you are buying an Obsidian CPU, a board with flashback such as the Kestrel B650M Wing is
the easier choice.

## Who it's for

Budget AM5 builders pairing it with a Quartz CPU, and office PCs that need modern DDR5 without
extras.

## Pros

- Affordable entry to AM5 and DDR5
- PCIe 4.0 M.2 and graphics slot
- Supports Quartz CPUs out of the box

## Cons

- Obsidian CPUs need BIOS 15, and there is no flashback to install it without a CPU
- Only one M.2 slot, NVMe only (no M.2 SATA)
- Two memory slots, 64 GB maximum
- No Wi-Fi

## FAQ

### Will it work with the Voltaris V5 8600?

Only after a BIOS update from 8 to 15, and without flashback you need a Quartz CPU such as the
V5 7600 installed to run the update. If you do not have one, choose the Kestrel B650M Wing (with
flashback) or the Kestrel B650 Aero, whose BIOS already supports Obsidian.

### Can I install 96 GB of memory?

No. The maximum is 64 GB in two slots, so the Nimbus Stratus DDR5-6400 96 GB kit is too large.
The Lumen Pulse DDR5-6400 64 GB (2x32 GB) is the largest kit that fits.

### Does it take an M.2 SATA SSD?

No. The single M.2 slot is NVMe only. Use a 2.5-inch SATA drive on one of the four SATA ports.
