## Overview

The Meridian B760M Forge D4 is a Micro-ATX motherboard for LGA1700 that uses DDR4 memory. It has
four DDR4 slots (up to 128 GB, rated to 4000 MT/s), two M.2 slots at PCIe 4.0 (the second also
accepts M.2 SATA drives), four SATA ports and a PCIe 4.0 x16 graphics slot.

The D4 in the name matters. LGA1700 CPUs work with DDR4 or DDR5, but each board supports only one
type, and this one takes DDR4 only. It is a great way to reuse an existing DDR4 kit. DDR5 modules
do not fit. It ships with BIOS 16, which supports both Falcon and Harrier CPUs (Harrier needs
BIOS 12). It has no Wi-Fi and no BIOS flashback.

## Who it's for

Budget LGA1700 builders and upgraders who already own DDR4 memory or want cheaper DDR4 kits.

## Pros

- Reuses DDR4 memory
- Supports Falcon and Harrier CPUs out of the box
- Two PCIe 4.0 M.2 slots
- Four memory slots up to 128 GB

## Cons

- DDR4 only; DDR5 kits do not fit
- No Wi-Fi
- No BIOS flashback

## FAQ

### Can I use a DDR5 kit?

No. This is the DDR4 version and DDR5 modules do not fit its slots. For DDR5 on LGA1700, choose
the Kestrel B760 Vector or the Meridian Z790 Crest.

### Will DDR4-3600 memory run at 3600?

LGA1700 CPUs officially support DDR4-3200, so a kit like the Lumen Pulse DDR4-3600 runs at
3200 MT/s by default. The board can run its 3600 MT/s profile when you enable XMP.

### Does it support the Helion H7 1470?

Yes. It ships with BIOS 16, and Harrier CPUs need BIOS 12.
