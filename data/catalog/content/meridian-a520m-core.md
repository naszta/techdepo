## Overview

The Meridian A520M Core is an entry-level Micro-ATX motherboard for AM4. It has two DDR4 slots
(up to 64 GB, rated to 3200 MT/s), a single M.2 slot at PCIe 3.0 that accepts both NVMe and M.2
SATA drives, four SATA ports and a PCIe 3.0 x16 graphics slot. It supports Granite CPUs such as
the Voltaris V5 5600 with the BIOS it ships with.

Keep the limits in mind when planning. Only one M.2 drive fits, so extra storage goes on SATA.
With two memory slots, a four-module kit cannot be installed. There is no Wi-Fi and no BIOS
flashback.

## Who it's for

Office, school and budget gaming builds on AM4 where every euro goes to the CPU or graphics card.

## Pros

- Very low price
- Supports every Granite CPU out of the box
- M.2 slot takes NVMe or M.2 SATA drives
- Fits Micro-ATX and larger cases

## Cons

- Only one M.2 slot
- Only two memory slots (64 GB max)
- PCIe 3.0 only, so Gen 4 SSDs run at Gen 3 speed
- No Wi-Fi

## FAQ

### Can I install two NVMe drives?

No. There is a single M.2 slot. Add a 2.5-inch SATA SSD such as the Arcwave S2 1 TB for more
storage, or choose the Kestrel B550 Glide, which has two M.2 slots.

### Will a 4x16 GB memory kit work?

No. The board has two memory slots, so a four-module kit does not fit. A two-module kit such as
the Nimbus Cirrus DDR4-3200 32 GB is the right choice.

### Does a PCIe 4.0 SSD work?

Yes, but at PCIe 3.0 speed, about 3500 MB/s.
